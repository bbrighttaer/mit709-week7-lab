# StudySpace Technical Debt Register

One row per finding you decided to "Register as debt" in `review-log.md`. Debt you choose to keep is a decision, so it needs an owner and a trigger for looking at it again.

- **Quadrant** (Fowler, 2009): reckless or prudent, and deliberate or inadvertent.
- **Interest:** what this debt costs each time the code is touched, and how often that happens (rarely, monthly, weekly).
- **Effort:** S (under an hour), M (half a day) or L (more).
- **Decision:** Pay now, Plan (say when) or Accept (say what would change your mind).
